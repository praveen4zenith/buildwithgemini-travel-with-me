# My agent: TravelWithMe
One-liner: A conversational agent that helps travelers discover, plan, and organize personalized trip itineraries with a catalog of destinations, activities, and accommodations.

Tool coverage:
- Memory: Traveler profile (budget tier, dietary preferences, travel style like adventure vs. relaxation, visited places, home airport/city)
- Tools: Search destinations and curated activities, look up seasonal weather advisories, save and export complete itineraries
- Catalog/UI: Destination highlight cards, daily itinerary schedule tables, and accommodation comparison cards
- Image gen: AI-generated scenic destination preview postcards and visual itinerary moodboards
- Sandbox: Currency conversions, daily per-person budget computations, and itinerary route cost breakdowns

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for budget and currency calculations, Google Maps / Places API integration, Cloud Trace observability
